# members/

研修者ひとりにつき1ファイル、`members/<your-name>.md` を追加する場所です。

## ファイル名のルール

```text
members/<name>.md
```

- 半角小文字・数字・ハイフンのみ（例: `taro.md`, `taro-yamada.md`）
- 大文字 / スペース / 日本語 / アンダースコアは使えません
- サブディレクトリは作りません

> このルールは [CI](../.github/workflows/training-check.yml) が自動でチェックします。
> 違反しているとPull Requestが赤くなります。

## 書き方

[_template.md](_template.md) をコピーして書き換えてください。

手順は [実習1](../exercises/01-clone-to-pr.md) を参照。

## 注意

**このファイルはPublicになる可能性があります。**
本名・住所・電話番号・所属先の非公開情報などは書かないでください。
書く内容は「チームメンバーに公開して問題ないこと」だけにしてください。
